💬 Discord Integration

The Discord notifier posts rich embeds to your configured webhook on every push, pull request, release, and workflow completion.

  • Setup: add DISCORD_WEBHOOK_URL secret to repository
  • Push events → neon cyan embed
  • Pull Request events → electric violet embed
  • Release events → gold embed
  • Workflow completion → green/red embed
  • Manual dispatch → custom message embed
